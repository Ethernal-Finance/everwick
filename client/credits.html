The artists behind Everwick.

Everwick combines its original simulation code with licensed pixel art. This page keeps the character artwork credits visible and easy to discover.

Liberated Pixel Cup character system

Universal LPC Spritesheet Character Generator

Citizen bodies, faces, hair, clothing, footwear, jewelry, and related layered character art use assets from the Liberated Pixel Cup ecosystem and the Universal LPC Spritesheet Character Generator.

Current Everwick LPC layer families: adult body and head bases, eyes, eyebrows, bob, afro, bedhead, braid, braid II, bangs, short bangs, long sleeve tops, short sleeve tops, pants, leggings, basic shoes, stud earrings, and simple earrings.

The upstream project contains artwork under multiple open licenses, including CC0, CC BY, CC BY SA, OGA BY, and GPL. Each asset keeps its original license obligations. Everwick maintains this visible credits page and points to the detailed upstream asset registry for source and license information.
